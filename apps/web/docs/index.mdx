ai-cli is a tiny, agent-native CLI for generating text, images, video, and audio with dead-simple commands. Use OpenRouter, connect directly to OpenAI and FAL, or run local Ollama and OMLX models.

## Quick start

<Steps>
  <Step>
    ### Install globally

    ```bash
    npm install -g ai-cli
    ```

  </Step>
  <Step>
    ### Set your OpenRouter key

    ```bash
    export OPENROUTER_API_KEY="your-key"
    ```

  </Step>
  <Step>
    ### Generate something

    ```bash
    ai image "a cute dog"
    ai video "a spinning triangle"
    ai text "explain quantum computing"
    ai text -P ollama -m qwen3:latest "explain this locally"
    ai audio speak -P openai "Thanks for trying ai-cli"
    ai audio transcribe -P openai recording.mp3
    ```

  </Step>
</Steps>
