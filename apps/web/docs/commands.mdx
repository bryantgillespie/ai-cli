## image

Generate images from a prompt.

```bash
ai image "a sunset over mountains"
ai image "edit this" < photo.png
```

### Options

<Properties>
  <Property name="-P, --provider" type="openrouter | openai | fal">
    Default provider for unqualified models.
  </Property>
  <Property name="-m, --model" type="string">
    Model ID. Prefix with `provider:` to mix providers.
  </Property>
  <Property name="-o, --output" type="path">
    Output file path or directory.
  </Property>
  <Property name="-n, --count" type="number" default="1">
    Number of images per model.
  </Property>
  <Property name="-p, --concurrency" type="number" default="4">
    Max parallel generations.
  </Property>
  <Property name="--timeout" type="seconds" default="300">
    Request timeout in seconds. Must be a positive integer.
  </Property>
  <Property name="--size" type="WxH">
    Image size (e.g. `1024x1024`). Not supported by Gemini image models — use
    `--aspect-ratio` instead.
  </Property>
  <Property name="--aspect-ratio" type="W:H">
    Aspect ratio (e.g. `16:9`).
  </Property>
  <Property name="--quality" type="string">
    Provider- and model-specific quality level. Supported by OpenAI and
    OpenRouter targets.
  </Property>
  <Property name="--style" type="vivid | natural">
    Style for compatible OpenAI models.
  </Property>
  <Property name="--no-preview" type="boolean">
    Disable inline image preview.
  </Property>
  <Property name="-q, --quiet" type="boolean">
    Suppress progress output.
  </Property>
  <Property name="--json" type="boolean">
    Output metadata as JSON.
  </Property>
</Properties>

Generated image files preserve the format returned by the selected model when
the model reports one (for example, JPEG, WebP, or SVG). In supported terminals, non-PNG images are converted to PNG
for the inline Kitty graphics preview. SVG previews use a 512-pixel long edge
and an opaque white background.

## audio

Generate speech from text or transcribe audio to text.

```bash
ai audio speak -P openai "Hello from ai-cli"
ai audio transcribe -P openai recording.mp3
cat voice-note.mp3 | ai audio transcribe -P openai -o transcript.txt
```

<Properties>

    Provider for this request.
  </Property>
  <Property name="-m, --model" type="string">
    Speech model ID. Prefix with `provider:` to mix providers.
  </Property>
  <Property name="-o, --output" type="path">
    Output file path or directory.
  </Property>
  <Property name="-f, --format" type="string" default="mp3">
    Audio output format. FAL speech targets support MP3 only.

    Instructions for speech generation.
  </Property>
  <Property name="--speed" type="number">
    Speech speed.
  </Property>
  <Property name="--language" type="code">
    Language code, such as `en` or `fr`, or `auto`.
  </Property>
  <Property name="-n, --count" type="number" default="1">
    Number of generations per model.
  </Property>
  <Property name="-p, --concurrency" type="number" default="4">
    Max parallel generations.
  </Property>
  <Property name="--timeout" type="seconds" default="120">
    Request timeout in seconds. Must be a positive integer.
  </Property>
  <Property name="-q, --quiet" type="boolean">
    Suppress progress output.
  </Property>
  <Property name="--json" type="boolean">
    Output metadata as JSON.
  </Property>
  <Property name="--no-play" type="boolean">
    Disable audio playback after generation.
  </Property>
  <Property name="--no-waveform" type="boolean">
    Disable accurate terminal waveform preview.
  </Property>
</Properties>

`audio speak` accepts text from an argument or stdin:

```bash
echo "Ship the changelog" | ai audio speak -P openai -o changelog.mp3
cat announcement.txt | ai audio speak -P openai --format wav -o announcement.wav
```

## evaluate

Ask named Boolean, Choice, and Score questions against shared stdin:

```bash
cat ticket.txt |
  ai evaluate \
    --boolean "refund=Refund requested?" \
    --choice "team=Which team?" \
    --choices "team=billing,support" \
    --score "tone=How positive?" \
    --levels "tone=angry,neutral,happy"

ai evaluate --questions triage.json < ticket.json
```

Output is the SDK evaluation result as JSON, including named typed answers,
probabilities, usage, provider metadata, and response information. Repeat question
flags to ask more questions in one request.
Text, JSON objects, and arrays remain one shared state.

Use `--questions` for structured instructions and criteria, `--input auto|text|json`
to control parsing, `--model` to choose one evaluation model, `--provider-options`
for the SDK’s provider-specific settings, and `--max-retries` or `--timeout` for request controls.

See [Evaluate](/docs/evaluate) for every flag, the question-file schema, probability
semantics, and examples of using the answers in scripts. Valid evaluations exit
zero even for false or uncertain answers; your code owns thresholds and routing.

## models

List available models for a provider, or show detailed info for one model.

```bash
ai models
ai models --type image
ai models --type evaluation
ai models --creator openai --json
ai models claude-opus-4.6
ai models anthropic/claude-sonnet-4.6 --json
```

### Arguments

<Properties>
  <Property name="[model]" type="string">
    Model ID or unique short name. Shows context window, max output, pricing,
    and release date.
  </Property>
</Properties>

### Options

<Properties>
  <Property
    name="-P, --provider"
    type="openrouter | anthropic | openai | fal | ollama | omlx | all"
  >
    Provider catalog to list. Use `all` for provider-qualified entries from
    every catalog.
  </Property>
  <Property
    name="--type"
    type="text | image | video | audio | speech | transcription | evaluation"
  >
    Filter by modality (list mode only).
  </Property>
  <Property name="--creator" type="string">
    Filter by creator (e.g. `openai`, `google`) (list mode only).
  </Property>
  <Property name="--json" type="boolean">
    Output as JSON with descriptions.
  </Property>
</Properties>

OpenRouter models are fetched from OpenRouter. Direct Anthropic and OpenAI metadata comes from models.dev. Ollama and OMLX use their local `/v1/models` endpoints. Cloud catalogs are cached locally for one hour.

## Timeouts

Requests that exceed the per-command timeout are aborted automatically:

| Command            | Timeout                           |
| ------------------ | --------------------------------- |
| `evaluate`         | 30 seconds per evaluation request |
| `text`             | 120 seconds                       |
| `image`            | 300 seconds                       |
| `video`            | 300 seconds                       |
| `audio speak`      | 120 seconds                       |
| `audio transcribe` | 120 seconds |

Image and video generation use a longer timeout because models typically need more processing time.

Use `--timeout <seconds>` to allow a longer request without changing models. The value must be a positive integer:

```bash
ai image --timeout 600 "a detailed sprite atlas"
```

## Exit codes

| Code | Meaning                                                  |
| ---- | -------------------------------------------------------- |
| `0`  | Success                                                  |
| `1`  | Invalid input or request failure; all generations failed |
| `2`  | Partial generation failure (some succeeded, some failed) |
