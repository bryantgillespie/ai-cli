## Install

```bash
npm install -g ai-cli
```

Or with another package manager:

```bash
bun add -g ai-cli
pnpm add -g ai-cli
yarn global add ai-cli
```

## Choose a provider

OpenRouter is the default provider. Set its API key:

```bash
export OPENROUTER_API_KEY="your-key"
```

To connect directly to another provider, set the provider and matching key:

```bash
export AI_CLI_PROVIDER="openai"
export OPENAI_API_KEY="your-key"
```

```bash
export AI_CLI_PROVIDER="fal"
export FAL_API_KEY="your-key"
```

You can also choose a provider per command with `-P` or `--provider`.

For local inference, start Ollama or OMLX and choose an installed model:

```bash
ai text -P ollama -m qwen3:latest "hello locally"
ai text -P omlx -m qwen3:thinking "hello locally"
```

The default endpoints are `http://127.0.0.1:11434/v1` for Ollama and `http://127.0.0.1:8000/v1` for OMLX. Override them with `OLLAMA_BASE_URL` or `OMLX_BASE_URL`. Local servers do not require keys unless configured with authentication.

<Properties>
  <Property name="OPENROUTER_API_KEY" type="string">
    OpenRouter API key. Supports text, image, and video generation.
  </Property>
  <Property name="OPENAI_API_KEY" type="string">
    OpenAI API key. Supports text, image, speech, and transcription.
  </Property>
  <Property name="FAL_API_KEY" type="string">
    FAL API key. `FAL_KEY` is also accepted. Supports image, video, speech, and
    transcription.
  </Property>
  <Property name="OLLAMA_BASE_URL" type="URL">
    Optional Ollama endpoint override.
  </Property>
  <Property name="OMLX_BASE_URL" type="URL">
    Optional OMLX endpoint override.
  </Property>
  <Property name="OLLAMA_API_KEY" type="string">
    Optional key for an authenticated Ollama endpoint.
  </Property>
  <Property name="OMLX_API_KEY" type="string">
    Optional key for an authenticated OMLX endpoint.
  </Property>
</Properties>

Add exports to your shell profile (`~/.zshrc`, `~/.bashrc`, etc.) to persist them.

## Verify

```bash
ai text "hello"
```

If you see generated text, you're ready.
